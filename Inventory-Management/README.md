# Inventory Management

## Overview
Built a Power BI dashboard analyzing inventory performance across 5 KPIs — stockout rate, forecast accuracy, holding cost, processing time, and cancellation rate — using DAX for automated tracking.

## Key Findings
- Identified a **−0.89 correlation** between demand-forecast accuracy and stockout rate, and a **+0.75 correlation** between order-processing time and cancellations — isolating the two root causes behind an **18.56% stockout rate** and **19.29% excess-inventory cost**.
- Recommended **ABC inventory classification** and **dynamic reorder thresholds** to rebalance stock allocation between best-selling and slow-moving products, without increasing total inventory investment.
